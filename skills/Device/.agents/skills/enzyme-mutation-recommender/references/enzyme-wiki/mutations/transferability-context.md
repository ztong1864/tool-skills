# Transferability And Context Failures

## Positive Transfer Cases

- IPYE-like NTD/TBD changes from chPylRS improved several PylRS-derived synthetases in [S03](../sources/S03-pace-aaRS-2017/summary.md), but the exact effect size varied by background.
- R19H/H29R/T122S from MmPylRS improved AcKRS and modestly improved AcdKRS in [S05](../sources/S05-evolving-ntd-2018/summary.md).
- CrtK-RS(4.1) NTD-biased mutations improved AynK-RS in [S08](../sources/S08-two-tier-screening-2017/summary.md).
- Com2-like TBD mutations improved multiple PylRS-derived synthetases in [S07](../sources/S07-ml-guided-pylrs-2025/summary.md).

## Context Boundaries

- R19H/H29R/T122S did not improve IFRS as expected in [S07](../sources/S07-ml-guided-pylrs-2025/summary.md).
- IPYE did not improve IFRS in the initial [S07](../sources/S07-ml-guided-pylrs-2025/summary.md) test.
- S01 reports that a mutation set useful in one origin may have negligible benefit when transferred to MbPylRS.
- Linker insertions in [S06](../sources/S06-linker-ntd-engineering-2020/summary.md) do not uniformly improve every scaffold.

## Recommendation Implication

Transferability is a hypothesis to test, not a property of a mutation name. A recommendation must state why the user's sequence resembles the source scaffold enough for transfer and what experimental comparison would falsify that transfer.
