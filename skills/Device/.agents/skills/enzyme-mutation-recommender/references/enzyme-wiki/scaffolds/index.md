# Scaffold Map

Use scaffold pages before interpreting any mutation. PylRS mutation evidence is scaffold-dependent: identical residue labels can mean different structural contexts across MmPylRS, MbPylRS, chimeric PylRS, IFRS, CrtK-RS, and linker constructs.

## Scaffold Rule

Before using a mutation as recommendation evidence, identify:

- enzyme origin and domain source;
- catalytic-pocket parent variant;
- NTD/TBD or linker state;
- tRNA partner and host;
- substrate and assay.

If a source does not provide enough information to map the mutation into the user's sequence, mark the mapping as unresolved rather than forcing equivalence.
