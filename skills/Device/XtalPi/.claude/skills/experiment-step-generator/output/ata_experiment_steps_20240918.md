# ATA实验步骤

## 反应体系
- 苯乙炔：0.1 mmol (10.21 mg, 63.1 μL), 1.0 equiv
- 正壬醛：0.12 mmol (17.07 mg, 19.5 μL), 1.2 equiv
- CuI：0.005 mmol (0.952 mg), 0.05 equiv
- (S)-1-(2-吡咯烷甲基) 吡咯烷：0.12 mmol (18.51 mg), 1.2 equiv
- 4A分子筛：20 mg
- 溶剂：DMSO 1 mL

## 实验步骤

1. 在圆底烧瓶中加入CuI (0.952 mg) 和 (S)-1-(2-吡咯烷甲基) 吡咯烷 (18.51 mg)。

2. 加入干燥的4A分子筛 (20 mg)。

3. 加入DMSO (1 mL)，在氮气保护下搅拌5分钟。

4. 加入苯乙炔 (10.21 mg, 63.1 μL) 和正壬醛 (17.07 mg, 19.5 μL)。

5. 室温下搅拌反应12小时。

6. 反应结束后，通过硅胶柱层析纯化，得到目标产物。

## 后处理
反应混合物用水稀释，乙酸乙酯萃取，合并有机相，无水硫酸钠干燥，浓缩，硅胶柱层析纯化（石油醚/乙酸乙酯 = 20:1）得到目标产物。

## 表征
NMR, HRMS, [α]D等。
