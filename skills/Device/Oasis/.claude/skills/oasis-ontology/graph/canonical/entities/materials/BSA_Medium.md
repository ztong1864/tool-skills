# Material: BSA Medium

id: material:bm-bsa-medium
name: BM / BSA Medium

BM means `BSA Medium`.

This material is a culture medium containing BSA and is used in the BODIPY lipid staining experiment as the baseline medium condition.

In plate layout interpretation:

- `BM` corresponds to the BSA group
- this group is used as the normalization baseline in downstream image analysis
