# Knowledge: BODIPY BM FM Medium Rules

id: knowledge:bodipy-bm-fm-medium-rules
name: BODIPY BM FM Medium Rules

This knowledge object records the long-term interpretation rules for `BM` and `FM` used in the BODIPY lipid staining experiment.

Core rules:

- `BM = BSA Medium`
- `FM = FFAs Medium`
- BM is the culture medium containing BSA
- FM is the culture medium containing free fatty acids
- adding FFAs is used to simulate the elevated blood lipid condition associated with fatty liver disease models

Usage guidance:

- in plate layout interpretation, `BM` should be mapped to the BSA group
- in analysis interpretation, `FM` should be mapped to the FFAs medium group
- in BODIPY analysis, the BSA group is used as the normalization baseline
- the FM group can be used as a comparison threshold group for candidate screening
