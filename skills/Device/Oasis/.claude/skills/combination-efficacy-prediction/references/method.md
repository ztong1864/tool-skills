# 计算规则与证据边界

设两种候选成分的输入靶点集合为 A、B，疾病基因集合为 D。靶点可以是已知关系或有来源记录的预测关系；计算时仅使用 PrimeKG 蛋白相互作用网络最大连通分量中的基因。有分数的疾病基因按来源内分数排序，前 10 个组成 t10 模块，最多前 50 个组成 t50 模块；不足时按实际数量计算。本地空 `overall_score` 不等于 0 分，不能靠基因名字母序选入有序模块；本地有分数基因不足 20 个时，尝试以 Open Targets 直接遗传关联补充。

对每个模块计算药物靶点到疾病基因的平均最近距离，并与度数匹配的随机靶点比较，得到单药邻近度 `z_A`、`z_B` 和两药靶点并集的 `z_AB`。`z<0` 表示相对于随机靶点更接近疾病模块。

两药靶点分离度为 `s_AB=d_AB-(d_AA+d_BB)/2`：`d_AB` 是 A 与 B 之间的双向最近距离平均值，`d_AA`、`d_BB` 是各自靶点内部的最近距离平均值。`s_AB>0` 表示两药靶点在网络中相对分离。单靶点药物没有可估计的内部距离，按 0 代入时两种不同单靶点药物几乎总会得到正分离度。因此两药均须至少有 2 个 PPI 可映射靶点，分离度才用于进入主排名；其余药对仍保留原始数值和 `separation_eligible=0` 供探索。

药对需要两药各有至少 2 个 PPI 靶点，并同时满足 t10 和 t50 模块内的 `z_A<0`、`z_B<0`，以及 `s_AB>0`，才进入排名。排名分数为：

```text
per_drug = (zA10 + zB10 + zA50 + zB50) / 4
union    = (zAB10 + zAB50) / 2
network_score = -(per_drug + union) / 2
```

分数越高表示在此网络规则下优先级越高。全部药对及缺靶点、零方差等状态保留在 `all_pair_metrics.csv`；只有满足门槛的药对进入 `ranked_pairs.csv`。单药蒙特卡洛采样种子由固定常数和 DrugBank ID 生成，候选表换行序不改变结果。`both_significant` 仅标记四个单药 z 值是否均小于 -1.64，不是排名门槛。`network_score` 不表示实测药效、协同概率或安全性。需要这些结论时，必须使用相应的实验测量与独立验证。
