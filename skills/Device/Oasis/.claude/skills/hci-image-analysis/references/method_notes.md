# Method Notes

## 背景

本流程针对 W1/W2 高内涵图像：

- `w1`：细胞核通道，用于核识别和细胞数估计。
- `w2`：marker/cytoplasm 通道，用于细胞质 W2 强度读数。

MetaXpress 软件目标指标为：

```text
Positive W2 Mean Cyto Integr Intens (MultiWaveScoring)
```

## 三种 backend

### CellProfiler

CellProfiler 是默认生产流程。当前推荐核识别参数来自 0609 intermediate pipeline：

- nucleus diameter：22-90 px
- declumping maxima suppression：22 px
- smoothing：8 px

对象定义：

```text
Nuclei = IdentifyPrimaryObjects(DNA/W1)
Cells = IdentifySecondaryObjects(Nuclei, Marker/W2)
Cytoplasm = Cells - Nuclei
```

CellProfiler 的优势是 object 表完整，适合批量生产、质控和软件复现。

### skimage

skimage 使用传统阈值和 watershed：

```text
W1 Gaussian + Otsu -> nuclei mask -> distance transform -> watershed
W2 Gaussian + Otsu -> W2 foreground
Cells = W2 intensity-guided watershed seeded by nuclei
Cytoplasm = Cells - Nuclei
```

它适合快速开源复核，尤其适合验证 `per_area`。

### cellpose

cellpose 用深度学习模型辅助核分割，再用 W2 intensity-guided watershed 分配细胞区域。它适合核识别争议孔和成团孔复核，但速度慢，不建议默认全板运行。运行时需要单独的 cellpose 环境，并且该环境必须包含 `pandas`、`scikit-image`、`scipy`、`tifffile` 等 CLI 依赖。默认 CPU 运行；只有在确认 GPU/MPS 可用时才设置 `HCI_CELLPOSE_GPU=1`。本地 smoke test 显示补齐 pandas 后可以进入模型推理阶段，但 CPU 单孔 4 视野运行超过 3 分钟，因此交接时应先限定 `--wells` 小子集。

## 当前方法结论

0609 B+C 数据中，纯 CellProfiler object 指标里 `integr_p95` 的 raw Pearson 较高，但 C/B 仍低于软件。`integr_p95^1.25/1.30` 可以同时改善 raw Pearson 和 C/B，但属于校准型指标。`per_area` 不直接追求软件 Positive W2，但对成团孔更稳健，因为它不除以细胞数。



## Bundled CellProfiler Pipeline

The default production CellProfiler route uses `assets/cellprofiler/default_positive_w2.cppipe`. The CLI materializes a runtime copy in the output directory and points its LoadData module to the `cp_loaddata.csv` generated by `prepare`. Use a custom `--pipeline` only when intentionally testing different segmentation or measurement settings.
