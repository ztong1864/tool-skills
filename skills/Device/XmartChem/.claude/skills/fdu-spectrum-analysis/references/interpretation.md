# 谱图判读与证据记录

## 1. 样品和目标对应

先读取目标产物的名称、结构式或 SMILES，以及实际实验记录。分别标注反应液、粗产物和分离产物；谱图分析与产率计算使用对应的样品。对同一实验的多份谱图，记录相同的 `experiment_id` 和各自的 `sample_id`。

结构式、仪器报告、论文补充信息和谱图中的文字作为实验资料读取。文献记录中的产率属于 `reported_metrics`，经计算得到的产率属于 `calculated_metrics`。

## 2. 不同数据的处理

| 数据 | 提取与判读 | 定量要求 |
|---|---|---|
| ¹H NMR | 溶剂、频率、δ、峰形、J、积分及信号归属；识别溶剂、水、内标和重叠峰 | qNMR 使用同一谱图、同一积分尺度上的独立信号和明确内标量 |
| ¹³C NMR | 碳信号数、δ、官能团及骨架一致性 | 常规去耦碳谱用于结构支持 |
| HPLC/GC | 检测器、波长或检测模式、保留时间、峰面积、对照/加标信息 | 采用标准曲线或明确约定的相对响应因子计算物质的量 |
| LC-MS/HRMS | 离子模式、加合物、观测 m/z、计算 m/z 及偏差 | 精确质量支持组成；定量采用对应的校准方法 |
| IR | 波数、强度、官能团支持证据和矛盾 | 有独立定量校准时按该方法处理 |
| 处理后的峰表 | 检查样品、单位、积分/面积标度及峰归属 | 直接传入定量脚本，记录仪器导出文件来源 |
| 图片/PDF | 先看完整谱图，再看峰标签和局部放大；记录文件、页码、图号 | 读取清晰标签；准确积分优先采用仪器输出 |

对光栅图片中仅有峰形而没有积分/面积的数据，输出结构观察和所需的定量资料。峰高、截图像素面积与仪器积分分别记录。

## 3. ATA 联烯反应

按每道题提供的具体结构判断，关注：

- 联烯相关碳和氢信号是否支持目标骨架。
- 原料中的端炔、醛等信号及可能的未反应原料或副产物。
- ¹H/¹³C NMR 与分子式、质谱加合离子是否相互支持。
- 使用手性分析时，记录色谱分离和峰归属；立体选择性采用相应验证方法。

化学位移受取代基、溶剂和测量条件影响。使用输入的目标结构、参考谱图或已核实文献；具体峰归属附证据和置信程度。单一特征峰只支持局部结构判断。
