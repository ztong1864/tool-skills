# ATA 端炔联烯化实验方案（草稿）

## 反应名称
端炔联烯化（ATA）反应构建联烯结构

## 反应目的
以苯乙炔和正壬醛为底物，在 ScCl3 与手性胺协同作用下进行 ATA 反应，构建目标产物中的联烯结构。

## 反应条件
- 苯乙炔：0.10 mmol，1.0 equiv
- 正壬醛：0.12 mmol，1.2 equiv
- ScCl3：0.005 mmol，0.05 equiv
- (S)-α,α-二苯基脯氨醇：0.12 mmol，1.2 equiv
- 分子筛：不加入
- 溶剂：DCE，1.0 mL
- 设备：复旦智能合成工作站

## 实验步骤
1. 在复旦智能合成工作站对应反应位中加入搅拌子，确认反应器清洁干燥。
2. 依次加入 ScCl3（0.05 equiv，0.005 mmol，0.83 mg）、(S)-α,α-二苯基脯氨醇（1.2 equiv，0.120 mmol，28.7 mg）和分子筛（不加入）。
3. 加入 DCE（1.0 mL），使固体充分分散/溶解，形成反应体系。
4. 加入苯乙炔（1.0 equiv，0.100 mmol，约 10.4 μL）和正壬醛（1.2 equiv，0.120 mmol，约 15–16 μL）。
5. 密封反应器，置于设定温和搅拌条件下进行反应，维持室温或按 ATA 反应常用条件执行，持续反应至预定时间。
6. 反应结束后，按设备或人工流程进行常规后处理、分离与纯化，获得目标联烯产物。

## 备注
- 当前方案中分子筛不加入。
- 液体体积为近似换算，若用于上机可进一步按实际密度校正。
