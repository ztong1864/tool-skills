# Site Index And Numbering Rules

## Numbering Rule

Every site page must state which scaffold uses the residue number. A site is not a universal coordinate unless an alignment supports it.

## Site Groups

- [N-terminal and tRNA-binding-domain sites](ntd-tbd-sites.md)
- [Catalytic-pocket sites](catalytic-pocket-sites.md)
- [Linker and domain-communication sites](linker-domain-sites.md)

## Mapping Confidence

- High: the source explicitly states homology or a direct sequence alignment was performed.
- Medium: the residue lies in a conserved motif and source/domain boundaries strongly support the mapping.
- Low: only approximate domain or literature analogy supports the mapping.
- Unresolved: do not use for direct recommendation without further alignment.
