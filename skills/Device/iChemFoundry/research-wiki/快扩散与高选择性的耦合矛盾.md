# 快扩散与高选择性的耦合矛盾

> 用户的诉求"动力学选择性 ↑ + 丙烯 τ ↓"是 selectivity-flux trade-off 的最难版本。理解为什么难,以及业界已知的三大化解路径。

## 矛盾的形式化

为提高动力学选择性 D(C3H6)/D(C3H8),通常需要做以下一项或多项:
- 收紧 PLD → C3H8 跳跃熵障 ↑↑,但 C3H6 跳跃熵障也会 ↑(只是涨得慢)
- 增强孔壁吸附位 → C3H8 取向陷获时间 ↑,但 C3H6 也会被陷获(`spmap_4a4a4bfdba39`:Henry K ↑ → D ↓)

但 D(C3H6) 大要求:
- PLD 不能太小(`spmap_551aaea9bad5`:PLD > 动力学直径才能快)
- 沿扩散路径**没有深吸附陷阱**(`lever_73920ed87c7f`:消除深陷阱可让 D 提升 1 个量级)
- 框架最好**适度柔性**(`spmap_82511f05f242`:柔性提升 D)

两组诉求**直接对撞**——尤其"加强吸附位"与"消除深陷阱"几乎完全对立。**典型失败**:HAF-2 把孔窗口收到几乎完全分子筛分丙烷,但 C3H6 / N₂ / CO₂ 也几乎无吸附与扩散(`tasks/C3H6_C3H8_separation.md` failure 警告);β-CALF-20 用窄孔做完美筛分但结构不稳定。

## 三大已知化解路径(本任务核心抓手)

### 路径 1:**几何解耦** — 局部收缩喉 + 悬挂口袋
来源:`drule_dde65b019e90`(原文献 a5f035406a01,显式声明"overcomes the usual capacity-kinetics trade-off")
- **思想**:窗口处只放一个尺寸做筛分的"喉",喉之后接一个稍大的口袋提供吸附与扩散空间
- **效果**:C3H6 通过喉以后进入口袋自由扩散,**整体扩散路径上"卡瓶颈"段很短**,τ 不被全程窗口拖累;同时 C3H8 在喉处直接被剔除
- **类比沸石**:类 RPZ / 沙漏型笼-窗结构
- **MOF 实现入口**:柱撑体长度 + 拓扑选择(让笼大、窗小)

### 路径 2:**差分功能化** — 让丙烷选择性慢
来源:`lever_de6a79ef8ba2`(壁面差分功能化)
- **思想**:在孔壁布置"对丙烷强相互作用、对丙烯弱相互作用"的官能团(利用 C=C π / 极化率差),只增加 C3H8 的取向陷获 + 驻留时间,不动 C3H6 路径
- **效果**:D(C3H6) 基本不变,D(C3H8) ↓,选择性 ↑
- **风险**:非选择性官能团会同时陷获丙烯(`lever_de6a79ef8ba2` risk),需要精确化学设计(优先选 π-interacting / 局部极性 / 立体定向基团)
- **MOF 实现入口**:配体官能化(优先)、金属源选择(改变 OMS 性质,但影响更宽泛)

### 路径 3:**几何 + 拓扑联合** — 适度筛分 + 不损平衡容量
来源:`lever_3a851c499a14`("introduce moderate kinetic discrimination without blocking equilibrium capacity")
- **思想**:不要把窗口收到极致,留在"适度筛分"区(D 比 ~10-100,而不是 ∞),保持腔体可达性 + 平衡容量
- **效果**:动选优势在突破中可持续到中后段(避免 `mprin_019ad6898ab3` 衰减);同时整体 τ 因留有通道可达性而不会暴涨
- **MOF 实现入口**:配体长度微调、互穿度调控、阴离子柱撑精细微调(KAUST-7 风格)

## 路径选择的判断准则

| 当前材料的瓶颈 | 优先路径 |
|---|---|
| 孔太大,选择性低,D 已足够快(如 ZIF-67 大孔类) | 路径 1 / 3(几何收缩) |
| 孔太小,D(C3H6) 不足(如 HAF-2 类) | 路径 1(几何解耦,留口袋给 C3H6 跑) |
| 孔合适但壁面无差分,选择性平 | 路径 2(差分功能化) |
| 平衡偏好丙烷,只能靠瞬态(如 ZIF-8) | 路径 2 + `lever_4a9f86686930`(加丙烯优先平衡位点) |

## 操作上的反命题(必须警惕)

- **以为更窄一定更好** → HAF-2 反例
- **以为加吸附位一定提高选择性** → 同时拖慢丙烯,τ 反而恶化(`spmap_4a4a4bfdba39` Henry-D 反相关)
- **以为换金属源都安全** → 改 OMS 会同时改吸附能 + 改连接几何 + 改稳定性,**回到 recomm_steps §66 的"一次只动一个组分"约束**
- **以为柔性总是好的** → 柔性提升 D 时,对大分子收益更大(`spmap_82511f05f242` 中 Kr > Ar > Ne),可能**反向降低选择性**

## 关键概念

- **selectivity-flux trade-off** — 经典分离工程矛盾,但 MOF 几何解耦提供突破口
- **dynamic vs equilibrium selectivity** — 见 [[丙烯丙烷动力学分离原理]]
- **deep binding trap** — 沿扩散路径的高吸附能点,导致 residence time 暴涨
