# 丙烯丙烷动力学分离原理

> 在床层未达平衡前,C3H6 与 C3H8 在 MOF 中的吸附比由"瞬态传质"主导,而不是平衡等温线;这是设计快扩散 + 高选择性材料的逻辑起点。

## 核心观点

1. **动力学选择性 ≠ 平衡选择性**(KB v4 `axiom_d565697b9f1f` / `axiom_73fc18a61f5b`,均标记 must_check)。在突破/PSA/VSA 等瞬态条件下,实际可分离比 S_d(t) 由各组分的扩散速率比 + 局部吸附量比共同决定,绝不能用 IAST 平衡选择性代替评估。
2. **何时动选占优**:当两组分的扩散系数比 D(C3H6)/D(C3H8) > 平衡偏好比 K(C3H6)/K(C3H8) 时,瞬态阶段会出现"丙烯先冲出、丙烷被滞留"的动力学分离窗口。Yang 2024 在 ZIF-8 中观察到:9 μm 晶粒平衡偏好丙烷(Henry C3H8/C3H6=1.13),但 224 μm 晶粒在突破中**丙烯先穿出**,即偏好被动力学反转(详见 [[ZIF-8动力学反转案例]])。
3. **动选会随接近平衡而衰减**(KB v4 `mprin_019ad6898ab3`)。若 K_平 > 1 偏好丙烷,而仅依赖动力学早期窗口,则突破中后段动选会向 K_平 收敛,因此**仅有动力学优势是不够的,必须配合不太差(或同向)的平衡选择性**(对应 `lever_4a9f86686930`)。
4. **扩散时间常数 τ ≡ r²/D**(`mprin_90c18a7c41d7` 的球形颗粒模型):τ 越小,吸附达到分数填充 m_t/m_∞=0.5 所需的 t_{1/2} ≈ 0.03 × r²/D 越短。本任务"丙烯扩散非常快" = "τ(C3H6) 小",即希望 D(C3H6) 大 / 颗粒半径小;但 recomm_steps 明确禁用粒径调控,因此**只能向 D(C3H6) 大的方向走**。
5. **τ 在两个尺度上独立存在**:晶内扩散 τ_intra(由孔结构决定,本项目重点) 与 表面/晶界渗透 τ_surf(skin effect)。`drule_6ddfca5a4292` 强调必须同时平衡两者,只盯住 τ_intra 可能被表面阻力卡瓶颈。

## 关键概念

- **S_d(t)** — 动态选择性(time-resolved selectivity),Yang 2024 提出的过程层指标
- **K_H** — Henry 吸附常数,决定低压平衡偏好;与 D 通常负相关(`spmap_4a4a4bfdba39`)
- **t_{1/2}** — 吸附半时,实验最可直接读出的 τ proxy
- **PLD** (pore-limiting diameter) — 限速窗口直径,决定 D 与选择性
- [[平移-旋转耦合扩散机制]] — 解释为何"丙烯小一点"在限域中可被放大成扩散选择性

## 原理知识总结

### 1. 任务核心挑战

丙烯（C3H6）和丙烷（C3H8）的物理化学性质极为相似：
- 动力学直径：C3H6 = 4.0 Å, C3H8 = 4.3 Å（差异仅~0.3 Å）
- 分子截面：C3H6 = 6.5×4.0×3.8 Å³, C3H8 = 6.8×4.2×3.8 Å³
- 沸点差异极小（225.46 K vs 231.02 K）

用户需求为**同时实现高动力学选择性+快速丙烯扩散**，这是一个trade-off优化问题。

### 2. 关键性能指标与最佳范围

#### 2.1 孔窗口（Pore Window）
- **最佳范围**：3.8-4.2 Å（位于C3H6和C3H8分子尺寸之间）
- 原理：窗口尺寸恰好允许较小的C3H6通过但限制较大的C3H8
- HAF-1: 4.04 Å (throat)，几乎完全筛分
- Milli-Zn-ATA: 4.1×3.8 Å²，优秀动力学筛分
- ELM-12: ~4.0 Å，2D zigzag channels

#### 2.2 孔腔体积/尺寸
- 孔腔应足够大以容纳目标分子（C3H6），提供吸附容量
- **连通性越强，扩散越快** — 互连孔道 > 一维孔道
- HAF-1的hanging pocket设计：收缩喉道+大腔体，同时实现筛分与容量
- 最佳策略：局部收缩喉道（筛分）+ 大通道区域（快速传输）共存

#### 2.3 Qst（等量吸附热）
- **C3H6 Qst最佳范围**：25-45 kJ/mol（适中）
- 过高（>50 kJ/mol）：扩散变慢（停留时间增加），再生困难
- 过低（<20 kJ/mol）：吸附容量不足
- ELM-12: Qst(C3H6) = 30 kJ/mol, Qst(C3H8) = 28 kJ/mol → 低热，快再生
- HAF-1: Qst(C3H6) = 65.88 kJ/mol → 极高，强结合但影响扩散速度
- 对于"快速扩散"需求，Qst偏低（25-35 kJ/mol）更有利

#### 2.4 扩散时间常数（D' = D/r²）
- 定义：D为晶内扩散系数，r为颗粒半径
- **D'越大 = 扩散越快**
- T = R²/(15D_T) 为第一统计矩（equilibration time constant）
- 关键数据对比：
  - HAF-1: D'(C3H6) = 3.0×10⁻⁵ s⁻¹
  - ZU-609: D'(C3H6) = 7.6×10⁻⁵ s⁻¹
  - Milli-Zn-ATA: D_intra(C3H6) = 2.96×10⁻¹² m²/min (晶内扩散系数)
  - ELM-12: C3H6达到平衡仅需~10 min（非常快）

#### 2.5 动力学选择性
- 定义：D'(C3H6)/D'(C3H8) 或 穿透时间差
- HAF-1: selectivity = 1.67×10⁷（完全筛分，C3H8不进入）
- ELM-12: kinetic selectivity = 204 @ 298K, 971 @ 308K
- Milli-Zn-ATA: kinetic selectivity = 60
- ZIF-8 (141μm): breakthrough selectivity = 2.0
- **用户目标**：高选择性(>100) + 快速扩散 → ELM-12类型最为平衡

### 3. 核心设计原理

#### 3.1 限域诱导的平移-转动耦合扩散
- 在纳米孔道中，分子扩散受平移运动、转动自由度与客体-孔壁相互作用耦合控制
- 不对称分子（如C3H8比C3H6更球形对称度差）承受更高的取向障碍
- **设计含义**：优化孔道截面使C3H6自由转动通过，但C3H8因尺寸-形状受阻

#### 3.2 趋于平衡降低动态选择性
- 动态选择性在初期最高，随着接近平衡而衰减
- 如果平衡偏好C3H8（如ZIF-8），则动态选择性会反转
- **设计含义**：需要兼顾瞬态动力学优势和平衡吸附偏好

#### 3.3 局部收缩喉道+大通道并存设计
- drule_57b7d8db9e8b: 局部收缩筛分通道与大传输通道共存
- 收缩处排除大分子，大通道确保已筛分分子快速扩散
- **这是同时实现高选择性+快速扩散的最佳策略**
- HAF-1: shrinkage throat (4.04Å) + hanging pocket + spacious channel (4.14Å)
- ZU-609: constricted sieving channel + larger transport regions

#### 3.4 表面渗透与晶内扩散的平衡
- 1/D_app = 1/D_intra + 3/(αl)
- D_app为表观扩散率，D_intra为晶内扩散，α为表面渗透率，l为特征扩散长度
- 大晶粒（mm级）：晶内扩散主导 → 高选择性
- 小晶粒（nm级）：表面渗透主导 → 选择性降低
- **毫米级晶粒是实现高动力学选择性的关键**

#### 3.5 三唑环顺式取向诱导V形配体构象
- btap/ATA类配体中三唑环syn取向驱动V形构象
- V形配体可以精确控制孔窗口尺寸和形状

### 4. 优化策略总结（从V4 Optimization Levers提取）

#### 策略A：降低扩散路径上强吸附位点密度
- 目标：降低停留时间和取向陷阱
- 方法：采用极性更弱的配体，稀释开放金属位点
- 效果：扩散系数可提升约1个数量级
- 风险：选择性和容量可能下降

#### 策略B：优化孔道截面以保证目标分子自由转动
- 目标：C3H6可自由重取向通过，C3H8受阻
- 方法：调节配体长度、位阻体积和柱撑体来控制孔径
- 最佳窗口：4.0-4.2 Å（刚好大于C3H6的3.8 Å截面但小于C3H8的4.2 Å）

#### 策略C：引入适度动力学筛分且不牺牲平衡容量
- 目标：C3H6扩散更快但两者最终都能到达吸附位
- 方法：调节配体刚性、柱撑尺寸、互穿程度
- 关键：用扩散和突破实验验证，不能只看平衡等温线

#### 策略D：功能化孔壁以诱导竞争分子取向陷获
- 目标：选择性增加C3H8的取向障碍
- 方法：引入可与C3H8选择性相互作用的官能团

### 5. 材料设计关键规则总结

1. **孔窗口需亚埃精度控制**在4.0-4.2 Å范围
2. **大通道+局部收缩并存**是解决选择性vs扩散速度trade-off的最佳方案
3. **毫米级晶粒**比纳米晶粒有利于动力学选择性
4. **柱撑体选择**直接决定层间孔窗口大小
5. **氮唑类配体**（tetrazole, triazole）对精确控制孔尺寸特别有效
6. **2D zigzag通道**有利于差异化扩散行为
7. **SO₄²⁻柱撑**可提供H-bond稳定窗口 + 分子识别功能
