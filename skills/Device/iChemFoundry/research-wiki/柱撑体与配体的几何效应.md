# 柱撑体与配体的几何效应

> 配体长度/弯曲角 与 柱撑体长度/体积 是把"原理上的孔窗口要求"转化为"具体组分替换空间"的两个最重要旋钮。**recomm_steps 明确要求每次优化只动 4 大组分中的 1 个**,本页给出每个旋钮在原理上能影响什么、不能影响什么,以保证方向推荐不串台。

## 配体(linker)

### 长度
- **直接影响 LCD 与 PLD**:配体越长,LCD 越大,但若拓扑不变,PLD 也跟着变大(可能损失选择性)
- **风险**:配体显著加长往往导致互穿(`axiom_fb01f1f61c09`)或塌孔
- **推荐变化幅度**:同拓扑下 ±1-2 个芳环 / ±3-6 Å,不能跳到完全不同的尺度
- **本任务用法**:在 ZU-609 / HAF / pillared-layer 类基底上,微调配体长度以"刚好"卡住 C3H8

### 弯曲角(bend angle)
- **机制**:V 形/角形配体(如 btap、bdc 衍生物)的弯角直接决定笼形/通道形(`mprin_28c2b2c3b9a6`)
- **微调入口**(`lever_09816eb6e03a` / `lever_24e80ebf9352`):通过三唑邻位取代、二面角偏置改变弯角
- **本任务用法**:把通道横截面从近圆调成椭/裂(对 C3H6 平面 sp² 友好,对 C3H8 折链不友好)

### 官能化(functionalization)
- **机制**:在配体特定位置引入 π / 极性 / 立体基团,以差分陷获丙烷(`lever_de6a79ef8ba2`)
- **常用基团**:-CH₃ / -CF₃(立体 + 弱极性)、-NH₂(对 C=C π 弱、对 C-H 一般)、-F(轻微极化)、-OH(强吸附,需谨慎)
- **本任务用法**:配体功能化是路径 2"差分功能化"的主入口,优先级高于金属源调整(更可控)

## 柱撑体(pillar)

### 类型与长度
- **2D 层 + 中性柱撑**(如 dabco、bpy、bpe、azpy):柱撑长度决定层间距(= z 方向 PLD/LCD)
  - dabco ≈ 2.6 Å、bpy ≈ 7.0 Å、bpe ≈ 9.4 Å、azpy ≈ 9.0 Å
  - 不同柱撑可给出 ~5-10 Å 的层间距连续可调,直接覆盖丙烯/丙烷敏感区
- **2D 层 + 阴离子柱撑**(`drule_80388b176ae0`,KAUST-7 范式):
  - SiF₆²⁻ / NbOF₅²⁻ / TiF₆²⁻ / SnF₆²⁻ / GeF₆²⁻ / SbF₆⁻ 等
  - 提供更精细的几何雕刻和静电场调控,孔形/孔径可独立调
  - F 在孔窗口处提供弱极性 + 立体凸起,直接作用于丙烷取向陷获
- **风险**:柱撑过短 → 层间堵塞;过长 → 互穿/塌孔
- **本任务用法**:柱撑替换是最有效的"窗口微调"组分入口

### 弯曲角 / 立体体积
- 较弯柱撑(如 dpe vs dpa)可改变 z 方向通道的弯曲度,影响 levitation / window-effect 强度
- 大体积取代基(柱撑上的 -CH₃ / -Cl)在柱撑近邻"凸起",直接卡丙烷过窗口

### **重要核验项**(recomm_steps §22)
**Zn-ATA 的现有结构中 ATA 同时参与 2D 层/双层主体和层间连接**，公式可写为 `[Zn2(ATA)3(ATA)2/2]`。在阶段 B 的核验中，对所有 pillared-layer 材料必须回原文核对层内配体和柱撑体身份，KB 偶尔会混淆两种功能角色。

这里必须避免另一个相反的误读：ATA 当前承担双重角色，**不代表柱撑功能位不可替换**。在保持金属节点连接向量、层间连接数、桥联长度和配位端基匹配的前提下，可以保留层内 ATA 主体，并用其他合适桥联体承担层间柱撑功能；这种组分替换不必改变目标拓扑。最终是否等拓扑仍需 SCXRD/PXRD 验证，但不能把“现有柱撑也是 ATA”写成拓扑上的不可替换约束。

## 金属源(metal source / SBU)

### 影响项
- 节点几何(配位数、连接向量) → 拓扑
- 开放金属位点 OMS 强度 → 平衡吸附偏好(对丙烯 C=C π 有较强亲和)
- 稳定性(高价金属如 Zr⁴⁺ / Cr³⁺ > Zn²⁺ / Cu²⁺)

### 本任务的使用注意
- 改金属源**几乎不可避免地同时改变拓扑 + 吸附能 + 稳定性**,违反 recomm_steps §66 的"一次只动一个组分"原则
- **优先级最低**,只在材料的金属确实是当前瓶颈时考虑(例:Zn²⁺ 不稳 → 换 Zr⁴⁺;无 OMS → 加 OMS)
- 推荐组分:Zn²⁺ / Cu²⁺ / Co²⁺ / Ni²⁺ / Zr⁴⁺(UiO 节点) / Cr³⁺(MIL 节点) / Y³⁺ / In³⁺ / Mg²⁺ / Fe²⁺/³⁺

## 拓扑(topology)

- 拓扑决定环数 / 通道维度 / LCD-PLD 比 (`spmap_98a3fbd7f9fb`)
- **改拓扑 = 整套结构重构**,本任务定位为"已有材料的优化",通常不动拓扑
- 仅在材料是"拓扑明显不利"(如纯大孔 IRMOF 类)时才考虑换拓扑;此时往往等于"换材料"而非优化
- 对应 `axiom_fb01f1f61c09`:配体几何固定拓扑,改拓扑通常需要同时改配体

## 组分换的优先级总结(本任务)

| 优先级 | 组分 | 何时换 | 风险 |
|---|---|---|---|
| **1** | 柱撑体 | 微调层间距 / 孔形(KAUST-7 范式) | 低,影响相对局部 |
| **2** | 配体(长度 / 弯角 / 官能化) | 微调通道截面与差分陷获 | 中,可能损互穿/容量 |
| **3** | 金属源 | OMS 不足或稳定性不够 | 高,几乎同时改多项 |
| **4** | 拓扑 | 几乎不动 | 极高,等于换材料 |

## 关键概念

- **SBU** (secondary building unit) — 金属节点的次级建筑单元
- **互穿(interpenetration)** — 配体过长时多个网络互相穿插,会显著改变孔结构
- **breathing / gate-opening** — 柔性骨架在压力/吸附下结构变化
