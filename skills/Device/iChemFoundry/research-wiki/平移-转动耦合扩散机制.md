# 平移-转动耦合扩散机制

> 在窄孔限域下,扩散选择性不再由分子尺寸决定,而是由"平移 + 旋转 + 主客相互作用"三者耦合决定 — 这是把 0.2 Å 的 C3H6/C3H8 动力学直径差异放大成数倍/数量级 D 比的物理根源。

## 核心观点

1. **机制公理**(KB v4 `axiom_0ad08aa5a58e`,must_check):当孔尺寸与客体动力学直径相当、且限制其转动自由度时,扩散选择性由 *coupled translation-rotation-host interactions* 决定,**而非单纯尺寸筛分**。设计窗口大小已经不够,还必须考虑:旋转受限带来的熵障、跳跃过窗口时的取向重定向代价。
2. **核心 Principle**(`mprin_e6a4d661d741`,cluster_size=4379 trace,confidence=0.88):限域扩散可呈现非单调、共振式甚至反直觉的尺寸-形状依赖。形状不对称 / 与孔壁相互作用更强的分子,会经历更长的"受限驻留 + 取向陷获",其 D 反而比更大但更对称的分子低。
3. **C3H6 vs C3H8 的物理差**:丙烯 C3H6 是平面 sp²(C=C),沿主轴有一个较小的最小投影(~4.0-4.2 Å),分子整体更对称;丙烷 C3H8 是 sp³ 折链,转动需扫过较大体积,在 5-5.5 Å 窗口中翻转/通过的熵罚显著高于丙烯。这种差异在大孔中消失(扩散趋同),只有在"刚好卡转动尺度"的窗口中才被放大成扩散选择性。
4. **形状-对称性比尺寸更决定 D**(`spmap_c77ae426d641`,confidence=0.67):卤代芳烃 C6H4F2 / C6H4BrF / C6H4Br2 的 D 分别为 1.25 / 0.93 / 1.14 × 10⁻⁸ m²/s,中间不对称分子最慢——经典 levitation 效应。这告诉我们设计孔形要与目标分子(C3H6)的对称性匹配,而让竞争者(C3H8)落入"几何不匹配"区。
5. **窗口效应的实验直接证据**(Pham Van 2025, SSZ-39 AEI):n-烷烃在 AEI 笼中 D 随链长呈现极大值(n-octane),Henry 常数与 D 反相关——典型的 Gorring "window effect"。机理:链长 ≈ 笼内长度时分子伸长穿过窗口最高效;过长时必须"折叠+重新展开"穿窗,代价骤升。这是 mprin_e6a4d661d741 在小孔沸石的实验印证,对 MOF 类比:**当 C3H6 与 C3H8 之一"恰好匹配"窗口取向能时,D 比可放大数倍**。
6. **框架柔性能整体提升 D**(`spmap_82511f05f242`,confidence=0.82):柔性骨架相对刚性骨架,Ne / Ar / Kr 的 corrected D 分别提升 22% / 82% / 239%——分子越大,柔性收益越大。**对丙烯/丙烷:适度柔性可能不仅让丙烯更快,也会让丙烷一起"加速过窗",需要在柔性 + 静态取向陷获之间细调**(高柔性 ≠ 高选择性)。

## 关键概念

- **取向陷获 (orientational trapping)** — 分子被困在不利于跳跃的姿态上,延长 residence time
- **重取向熵障 (rotational entropy barrier)** — 通过窗口必须先把分子轴对齐通道方向的代价
- **共振扩散 / window effect** — D 随链长/尺寸出现非单调极大值
- **levitation 效应** — 大小适中、对称性匹配的分子在孔中"悬浮"快移
- [[孔窗口与扩散选择性]] — 把本机制转化为具体的孔窗口设计参数
- [[柱撑体与配体的几何效应]] — 通过组分调控耦合机制的工程入口

## 风险/反命题(必须记住)

- 在弱相互作用或大孔(mesopore)中,该机制几乎消失,D 回到"小分子更快"的常规规律(`mprin_e6a4d661d741` potential_counter_principle)。
- 若骨架柔性 / gate-opening 主导,静态限域分析会失效,需要补 DFT/MD 验证。
- 若过度强化壁面相互作用,目标分子也会被陷获(`lever_de6a79ef8ba2` 风险条目)。
