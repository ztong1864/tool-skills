# 扩散测量与时间常数量纲

> 在阶段 B 候选材料"排名"前必须解决:KB 里的扩散数值五花八门(D / D_s / D_t / D_c / τ / t_{1/2}),只有把它们换算到同一量纲下比较才能避免误排名。本页给出对照表与核验方法。

## 扩散系数的几种定义

| 符号 | 名称 | 定义 | 单位 | 适用场景 |
|---|---|---|---|---|
| D_s | self-diffusivity(自扩散) | 单分子均方位移 MSD ~ 6 D_s t(3D) | m²/s | PFG NMR / MD,平衡条件单分子追踪 |
| D_t | transport diffusivity(传输扩散) | Fick 第一定律 J = -D_t ∇c | m²/s | ZLC / 突破实验 / 膜渗透 |
| D_c | corrected diffusivity(校正扩散) | D_t = D_c × Γ,Γ=∂ln p/∂ln c | m²/s | 与浓度无关,理论比较常用 |
| D_0 | low-loading limit | D_s @ c → 0 | m²/s | 内秉性能,适合材料间比较 |
| τ | diffusion time constant | r² / D | s | 球形颗粒模型,衡量整体吸附速率 |
| t_{1/2} | half uptake time | m_t/m_∞ = 0.5 时刻 | s | 直接实验读数;t_{1/2} ≈ 0.03 × r²/D_t |

## 关键换算关系

- **D_s ≈ D_c ≈ D_0**(在低负载极限)
- **D_t = Γ × D_c**(Γ 通常 > 1,高吸附压时可达 10-100,使 D_t > D_s)
- **τ = r² / D**(球形颗粒,r=代表性半径,见 `mprin_90c18a7c41d7`)
- **t_{1/2} ≈ 0.03 r²/D**(球形,Crank 1975)
- **τ 与膜渗透率 P 关系**:P = D × S(S 为溶解度),与本任务 τ 概念互补但不同

## 高/低负载差异(必看)

- `spmap_c5814fcb23bd`:D_s 通常随负载升高而下降(低-中负载),但部分笼状体系出现非单调(到接近饱和时回升,如某体系从 6.5→0.9→4.4 × 10⁻¹⁰ m²/s)
- **后果**:报"D=X m²/s"时若未注明负载,数据可差 1-2 个量级
- **核验做法**:阶段 B 报每个材料 D 时必须同时记录:负载 / 温度 / 压力 / 测量方法,并尽量统一到 D_0 或常用 1 bar 295-298 K 条件

## 微观 vs 宏观测量差异

- **微观**(PFG NMR / QENS):测 D_s,小尺度(~μm)无表面阻力影响
- **宏观**(ZLC / 突破 / 重量法):测 effective D 或表观 D_t,**含晶界 + skin effect 阻力**
- 两者可以差 1-3 个数量级(`diffusive-skin-effect-in-zeolites` 的核心观察)
- **后果**:同一材料的"D = 10⁻¹⁰ m²/s"(宏观)与"D = 10⁻⁸ m²/s"(PFG)并存属于正常,需标注方法

## τ 的两层结构

来源:`drule_6ddfca5a4292` "balance intracrystalline diffusion and surface permeation"

```
总扩散时间 τ_total = τ_intra + τ_surf
```

- **τ_intra** = r² / D_intra:晶体内部传质;本任务材料层优化主要影响这部分
- **τ_surf** = δ / k_surf:晶界/表面薄壳传质;由颗粒形貌、缺陷化学、活化质量控制
- **若 τ_surf 主导**(如有 skin effect 或孔口被合成残留物堵塞),无论怎么改晶内 D 都无效
- **诊断**:Yang 2024 在 ZIF-8 上的现象——大晶粒(224 μm)出现明显 surface barrier(`diffusive-skin-effect-in-zeolites`),小晶粒(9 μm)主要受晶内控制
- **本任务约束**:recomm_steps 禁用晶粒尺寸调控,因此实质上是要求**通过材料层优化让 D_intra 足够大**,把 τ_intra 降到与 τ_surf 同量级以下

## 分级孔(hierarchical pore)的扩散时间合成

`spmap_ef4c6f3b4afb`:当晶体同时含介孔与微孔,总吸附/扩散时间 τ ≈ τ_micro(微孔填充时间)
`spmap_8cd8893c32e8`:快交换条件 t_i / t < 1(域寿命短于扩散时间)

**对设计的含义**:加介孔通道可以缩短大尺度传输路径,但**最终速率仍由微孔填充控制**;因此对本任务,优先优化微孔窗口/通道(R1-R4),分级孔结构是辅助。

## 阶段 B 数据核验清单

对每个候选材料的扩散数据,核对以下字段:

| 字段 | 必须明确 | 示例 |
|---|---|---|
| 物理量 | D_s / D_t / D_c / τ / t_{1/2} | "D_t @ 1 bar, 298 K, ZLC method" |
| 温度 | K | 273 / 298 / 323 / 353 |
| 压力或负载 | bar 或 mmol/g | 1 bar / 0.5 mmol·g⁻¹ |
| 颗粒尺寸 | μm(用于 τ = r²/D 反算) | 5 μm |
| 测量方法 | PFG / QENS / ZLC / 突破 / 重量 | "uptake-curve fitting" |
| 文献来源 | DOI/source_paper id | "yang-2024, paper 9fbde6b04aa6" |

## C3H6 传质数据的已核验标尺

| 材料 | 原文指标 | 条件/方法 | 可比性说明 |
|---|---:|---|---|
| ZSTU-10 | `D=4.29×10^-9 cm² s^-1` | 298 K, 1 bar, time-dependent uptake 拟合 | 可与同文列出的 ZU-609/KAUST-7 体积法值比较 |
| ZU-609 | `D≈1.00×10^-9`（4.8 μm）和 `1.36×10^-9 cm² s^-1`（26.8 μm） | 298 K, volumetric uptake | 同文另有频率响应值 `2.38×10^-9 cm² s^-1`，不可混成一个测法；目前看它是“快扩散优先”路线的核心标尺 |
| KAUST-7 | `D≈9.49×10^-11 cm² s^-1` | ZU-609/ZSTU-10 原文对比表 | 注意单位是 `cm² s^-1`，即约 `9.49×10^-15 m² s^-1`，不是 `10^-10 m² s^-1`；其价值更多在高筛分而非超快扩散 |
| MAF-60 | `D/r²=2.61×10^-3 s^-1` | 298 K, 1 bar, uptake 拟合 | 时间常数倒数，不能与绝对 D 直接数值比较 |
| Zn2(datrz)2CO3-180 | `D/r²=5.93×10^-3 s^-1` | 298 K, uptake 拟合 | C3H6 很快，但 C3H8 为 `2.90×10^-3 s^-1`，纯动力学比仅约 2 |
| HAF-1 | `D/r²=3.0×10^-5 s^-1` | 298 K, 1 bar, uptake 拟合 | 同文同法 ZU-609 为 `7.6×10^-5 s^-1` |
| NCU-20 | `D/r²=2.32×10^-5 s^-1` | 298 K, uptake 拟合 | 原文明确称室温扩散速率常数偏低 |
| Milli-Zn-ATA | `Dapp=1.90×10^-12 m² min^-1`；`Dintra=2.96×10^-12 m² min^-1` | 298 K, 1 bar, micropore diffusion model | 单位为每分钟；换算为每秒分别约 `3.17×10^-14`、`4.93×10^-14 m² s^-1` |

> 候选排名优先在同一指标族内部比较：绝对 `D` 对绝对 `D`，`D/r²` 对 `D/r²`。跨指标只能作数量级和证据层级判断，不能机械排序。
