# MOF 动力学分离设计策略汇总

> 把前面 5 个主题页中的原理 + lever + drule 浓缩为 **7 条可直接用于优化方向推荐的设计规则**。每条规则都指明:做什么、为什么、用哪个组分入口实现、风险是什么。

## 设计规则汇总(R1-R7)

### R1. 把 PLD 精调到"丙烯刚好自由旋转、丙烷取向受阻"区间
- **原理**:`axiom_0ad08aa5a58e` + `mprin_e6a4d661d741` + `lever_ab9cfdd1333e`
- **目标 PLD**:静态 3.8-4.5 Å,动态可扩张到 4.0-4.6 Å
- **组分入口**:**柱撑体**(优先,可精细微调)、配体长度/弯角(次)
- **风险**:窗口过窄会同时拖慢丙烯;过宽则两者都不受限
- **量化关联**:`spmap_551aaea9bad5` PLD > 动力学直径才能快;`spmap_82511f05f242` 适度柔性放大 D 但选择性可能下降

### R2. 沿扩散路径**消除**深吸附陷阱(尤其裸 OMS / 强极性基团)
- **原理**:`lever_73920ed87c7f` + `spmap_4a4a4bfdba39`(Henry-D 反相关)
- **目标**:沿 1D 通道 / 笼-笼通路上消除强吸附 hot spot,允许丙烯连续跳跃
- **组分入口**:**配体**(去掉/封端强极性基团)、金属源(改少 OMS 数量)
- **风险**:吸附削弱过度会同时降平衡选择性;若与 R1 同步收紧 PLD 则更危险
- **预期效果**:`lever_73920ed87c7f` 文档承诺 D 可提升 ~1 个数量级

### R3. 在孔壁做**差分功能化**:对丙烷选择性陷获,对丙烯放行
- **原理**:`lever_de6a79ef8ba2` + `axiom_0ad08aa5a58e`
- **目标**:利用 C3H6(平面 sp²,可极化)与 C3H8(折链 sp³)的取向/极化率差,布置 π-acidic / 立体定向基团让丙烷"卡姿势"
- **组分入口**:**配体官能化**(优先)、柱撑体上的 F / Cl 等
- **风险**:非选择性官能化会同时陷获丙烯;过强会增加再生能耗
- **典型实现**:KAUST-7 用 SiF₆²⁻ 的 F 在窗口处对丙烯/丙烷做不同取向作用

### R4. **几何解耦**:窗口处局部收缩喉 + 内部悬挂分子口袋
- **原理**:`drule_dde65b019e90`(原文献 a5f035406a01:"overcomes the usual capacity-kinetics trade-off")
- **目标**:窗口做筛分(对丙烷"卡死"),口袋做吸附/扩散(对丙烯快通过 + 强结合)
- **组分入口**:**拓扑/柱撑体组合**(选择能形成笼-窗-笼几何的 SBU + 柱撑配对)
- **风险**:能给出该几何的拓扑较少,合成挑战大;若口袋过大则平衡偏好可能反转
- **类比**:类 RPZ / 沙漏型几何

### R5. **多氢键稳定窗口**以抑制热致扩张
- **原理**:`drule_8dc585cd8f4b` + `drule_2dd074b3af3c`
- **目标**:窗口周围布置 ≥ 10 对氢键(N-H···N / O-H···O),保持 298-353 K 性能稳定
- **组分入口**:**配体**(选含 N-H / O-H / -COOH 等给质子基团的氮唑/酰胺类)
- **风险**:H-bond 网络也会引入亲水性,在湿气下可能损稳定性
- **典型实现**:HOF / 含 H-bond 网络的 MOF(如 HAF-1)

### R6. **适度动力学筛分**而不损平衡容量
- **原理**:`lever_3a851c499a14` + `mprin_019ad6898ab3`
- **目标**:动选窗口不要做到 ∞,留在 D 比 10-100 区间,保留腔体可达性
- **组分入口**:配体长度微调、互穿度调控、柱撑体细微调
- **风险**:筛分过弱则动选优势不足;留意突破后段衰减
- **核心配套**:同时执行 `lever_4a9f86686930`(加丙烯优先平衡位点)防止动选衰减

### R7. **疏水化通道环境**(去掉裸 -OH、避免亲水极化沿通道方向)
- **原理**:`spmap_4b8f34af69c4`(0.6 nm 限域下疏水孔 D ≈ 5× 亲水孔)
- **目标**:让丙烯/丙烷在窄孔中接近 bulk-like 跳跃,保 D
- **组分入口**:**配体**(用芳香骨架 / -CH₃ / -CF₃ 替代 -OH / -NH₂)、金属源(选无 OMS 的节点)
- **风险**:疏水化会同时降低 C3H6 平衡吸附偏好,需与 R3 / R6 配合
- **与 R5 的关系**:R5 H-bond 是窗口"边缘"亲水,R7 是孔壁通道"沿线"疏水,两者可共存

## 规则之间的相容矩阵

| | R1 PLD | R2 去陷阱 | R3 差分功能化 | R4 几何解耦 | R5 H 键稳口 | R6 适度筛分 | R7 疏水化 |
|---|---|---|---|---|---|---|---|
| **R1** | — | ⚠ 联用易过收 | ◎ 强协同 | ◎ R4 是 R1 的强化版 | ◎ 强协同 | ◎ 同方向 | ✓ |
| **R2** | ⚠ | — | ⚠ 矛盾(R3 加陷阱,R2 去陷阱) | ✓ | ✓ | ✓ | ◎ 强协同 |
| **R3** | ◎ | ⚠ 矛盾 | — | ✓ | ✓ | ◎ | ⚠ R7 可能去掉 R3 的 π/极性 |
| **R4** | ◎ | ✓ | ✓ | — | ◎ | ◎ | ✓ |
| **R5** | ◎ | ✓ | ✓ | ◎ | — | ✓ | ⚠ R5 亲水 vs R7 疏水 |
| **R6** | ◎ | ✓ | ◎ | ◎ | ✓ | — | ✓ |
| **R7** | ✓ | ◎ | ⚠ | ✓ | ⚠ | ✓ | — |

◎=强协同 / ✓=兼容 / ⚠=有冲突或需仔细权衡

**关键观察**:R2(去深陷阱)与 R3(差分功能化)看似冲突,实际上**只要"陷阱专门作用于丙烷取向"** 就能共存——这正是 `lever_de6a79ef8ba2` 的精髓:差分功能化 ≠ 普遍加陷阱。

## 优化方向决策树

```
Q1: 当前材料的 PLD 在 [3.8, 4.5] Å 区间内吗?
├── 否,过大:R1 收紧(改柱撑/配体长度)→ 推荐方向
└── 是 ┬→ Q2: 通道内有强吸附/极性 hot spot 吗?
       ├── 是:R2 / R7 去掉 → 推荐方向
       └── 否 ┬→ Q3: 选择性已经够,但 τ 太大吗?
                ├── 是:R4 几何解耦 → 推荐方向
                └── 否 ┬→ Q4: 动选随接近平衡衰减吗(平衡偏好丙烷)?
                         ├── 是:R3 / R6 + lever_4a9f86686930 → 推荐方向
                         └── 否 → 已较优,只剩 R5 高温稳定化
```
