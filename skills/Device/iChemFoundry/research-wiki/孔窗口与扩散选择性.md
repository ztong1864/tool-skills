# 孔窗口与扩散选择性

> 孔窗口 = 把"丙烯快速通过 + 丙烷被卡住"两条诉求**同时**写进结构里的关键设计变量。但单看 PLD 不够——同 PLD 下 D 可差 3 个数量级。

## 核心观点

1. **基准动力学直径(常用值)**:C3H6 ≈ 4.0-4.2 Å(动力学直径) / 4.65 Å(σ_min);C3H8 ≈ 4.3-4.5 Å。两者几何差仅约 0.2-0.3 Å,因此**窗口必须落在 4.0-4.5 Å 这极窄区间**内才有动力学窗口效应。低于 4.0 Å → 两者都进不来(HAF-2 失效原型);高于 5.0 Å → 两者都不受限,选择性消失。
2. **同 PLD 下 D 可差 3 个数量级**(`spmap_551aaea9bad5`):甲烷在 1D 沸石的 D 即使孔径相近也可差 ~10³ — 说明 PLD **必要但不充分**。还要管:通道维度(1D/2D/3D)、通道是直/弯、窗口形状(圆/椭/裂)、节点几何。
3. **拓扑决定环数与窗口形状**(`spmap_98a3fbd7f9fb`):12 元环 AFI/MAZ 给出 ~7.3-7.4 Å 圆截面;18 元环 VFI 给出 12.7 Å;SBA-15 给出 20 Å。**目标"丙烯快+丙烷卡"应聚焦到 8-12 元环 / 类 SOD / 类 RPZ 区间**(即等效 4-5 Å 窗口),而 ZIF-8 (SOD, 3.4 Å 静态窗口 → 动态 ~4.0-4.2 Å) 正落在这区间。
4. **柔性窗口(gate-opening / breathing)是双刃**(`spmap_82511f05f242`):动态扩张窗口能让丙烯通过门,但同时也能放过丙烷,需要"对丙烯打开 + 对丙烷依然关闭"的取向选择性门(参考 ZIF-8 + KAUST-7 的不同机制)。
5. **多氢键稳定窗口可防止热致扩张**(`drule_8dc585cd8f4b` / `drule_2dd074b3af3c`):在超微孔 MOF 中,在窗口处加 10 对 H 键,可在 298-353 K 内维持 C3H6 高吸附 + C3H8 几乎零吸附 — 比单纯"窄通道"稳健得多。
6. **局部收缩喉 + 悬挂分子口袋 = 越过容量-动力学权衡的关键拓扑**(`drule_dde65b019e90`):用一个局部窄"喉"做分子筛分,后面接一个稍大的口袋提供 C3H6 高吸附位点——把"窗口要小"(选择性)与"腔体要大"(D 与容量)解耦。这是本任务最具潜力的几何 motif 之一。
7. **阴离子柱撑可独立调控孔形/孔径**(`drule_80388b176ae0`,典型 KAUST-7 的 SiF₆²⁻ / NbOF₅²⁻):2D 层做主体几何,阴离子柱撑做精细几何雕刻,**孔形/孔径成为可独立旋钮**——为方向推荐提供了清晰的"换柱撑"组分空间。
8. **疏水比亲水更利于在窄孔保持快扩散**(`spmap_4b8f34af69c4`):0.6 nm 限域下,疏水孔的 CO2 D 可达亲水孔的 5 倍。对烃类(C3H6/C3H8 均非极性),**优先选低极性配体环境**(避免裸 OMS、避免裸 -OH 在通道方向)以让丙烯保持快扩散。
9. **1D vs 2D 通道**(Alaithan 2021):1D 10-ring 沸石(MTT 4.5×5.2 / TON 4.6×5.7 / MRE 5.6×5.6)中丙烯 D 与 2D MFI 同 accessible volume 下相近。**1D 通道在窗口完美匹配时具有最强动力学选择性**,但缺点是"分子塞车"敏感、对缺陷/孔口堵塞敏感(对应 [[扩散测量与时间常数量纲]] 的 skin effect)。

## 关键概念

- **PLD (pore-limiting diameter)** — 通道最狭窄处直径,决定分子能否通过
- **LCD (largest cavity diameter)** — 腔体最大直径,与 PLD 的差决定吸附位点容量
- **gate-opening pressure** — 柔性骨架开门所需压力,影响动选窗口的"开-关"
- **窗口取向选择性** — 同一窗口对不同分子取向的不同通过率,是 mprin_e6a4d661d741 在窗口尺度的体现

## 设计参数小结(供方向推荐用)

| 参数 | 推荐范围(以 C3H6/C3H8 任务) | 关联组分 |
|---|---|---|
| 静态 PLD | 3.8-4.5 Å(动态可扩张到 4.0-4.6 Å) | 配体、柱撑体、拓扑 |
| 通道维度 | 优先 1D 直通道或互锁的 3D 笼-窗系统 | 拓扑、互穿度 |
| 窗口刚性 | 中等(过刚易堵,过柔易漏丙烷) | 配体共轭/H 键、柱撑体长度 |
| 孔壁极性 | 低-中(避免裸 OMS 沿通道方向) | 金属源(改 OMS 数量)、配体(去极性基团) |
| 几何 motif | 收缩喉 + 悬挂口袋 / 阴离子柱撑 + 2D 层 | 柱撑体、拓扑 |
