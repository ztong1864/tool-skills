# MOF候选材料推荐 Pipeline

你正在执行一个MOF材料发现项目中的**候选推荐任务**。这是一个专业的、多阶段的长程任务，目标是根据用户的材料需求，从知识库出发，推荐有潜力的已有材料，并给出针对性的优化方向，最终输出一份详细的中文候选推荐报告。

## 首要步骤：启动 planning-with-files

在开始任何实质性工作之前，你**必须**先调用 `/planning-with-files` skill 来创建和维护 plan 文件。这对于这个长程任务的进度追踪至关重要。

调用方式：使用 Skill 工具，skill 名为 `planning-with-files:plan-zh`，不传参数即可。

然后基于下方的完整 pipeline 步骤设计你的 plan。plan 中应清晰体现三大阶段及其子步骤，并在每个阶段完成后更新 progress.md。

## 数据来源

- **KB V4**：稳定版知识库，位于 `memory/knowledge_base/v4/`
  - 原理知识库：`v4/principle/`（含 principles、playbooks、axioms、opt_levers、wiki 等）
  - 材料知识库：`v4/material/`（即 KB V3.4 的材料数据）
- **KB V3.4**：`memory/knowledge_base/v3.4/structured/`（含 experience、playbooks、skilllets、documents 等）
- **research-wiki**：`research-wiki/`（已有的原理性总结，需要在阶段一更新）
- **相关文献**：`相关文献/`（原始 PDF 文献，含扩散相关文献子目录）

## 用户需求

用户在调用此 skill 时传入的参数就是材料需求描述。例如：
> "帮我设计同时具有高C3H6/C3H8动力学分离选择性且丙烯扩散非常快（看扩散时间常数）的最佳材料。"

你需要始终围绕用户的具体需求展开所有分析和推荐。

# 阶段一：优化原理知识获取与推理

目标：从原理/机制角度理解，要满足用户需求，材料在原理和规则上应该满足什么条件。

## 步骤

### 1.1 从经验层学习

从 KB V3.4 的经验层（`v3.4/structured/experience/`）和 playbooks 中，寻找与用户需求相关的总结或知识进行学习。这些 playbook 和 skilllet 文件以 JSON 格式存储，包含了前期积累的实践经验。

### 1.2 从原理知识库深度学习

从 KB V4 的原理知识库（`v4/principle/`）中系统学习相关原理。重点关注：
- principles 目录下的原理条目
- playbooks 目录下的原理 playbook
- axioms 目录下的公理性知识
- opt_levers 目录下的优化杠杆
- wiki 目录下的原理 wiki

同时阅读 `相关文献/扩散相关文献/` 中的相关文献来补充理解。

关注的核心原理包括但不限于：扩散机制、气体分离原理、氮唑类材料特性等。

### 1.3 建立关键指标理解

你需要理解以下关键指标及其最佳范围：
1. **孔窗口**（pore window aperture）：控制分子筛分，范围的好坏直接决定选择性
2. **孔腔体积/尺寸**（pore cavity）：较大孔腔+高连通性有利于快速扩散
3. **Qst**（等量吸附热）：反映主-客体相互作用强度
4. **扩散时间常数**（diffusion time constant, D/r²）：直接衡量扩散速度
5. **动力学选择性**（kinetic selectivity）：目标分离性能的核心指标

通过文献学习，建立对这些指标"什么范围是好的"的定量认知。

### 1.4 保存阶段性总结

将所有学到的原理性知识**使用中文**保存在 `research-wiki/` 目录中，作为阶段性总结。更新已有文件或创建新文件均可。同时更新 `research-wiki/index.md` 索引。

# 阶段二：已有材料候选推荐

## Step 1：初步筛选候选材料

目标：结合原理知识，从知识库中筛选出与用户需求极其相关的、有潜力的候选材料作为研究起点。

### 要求

1. 充分利用 KB V4 材料知识库（`v4/material/`，即 V3.4 数据库），获取用户任务相关的材料信息
2. 从 V3.4 的 skilllet 和 playbook 中获取特定任务的材料信息
3. 重点关注：
   - 哪些材料在用户需求上已有研究/优化，与需求高度相关
   - **分析各材料的结构、几何，结合原理知识判断潜力**——潜力比现有性能更重要
4. 推荐可以通过后续优化达到用户**全部需求**的材料（如果需求有多条）
5. 推荐至少 **10个** 已有候选材料
6. 为每个推荐提供充分证据
7. 可以将**同类材料**（原料一致但合成条件不同导致构型微变）放在一起考虑

## Step 2：原始文献验证

KB 中的信息与原始文献一一对应。对于 Step 1 给出的每一个材料，你**必须阅读对应的原始文献**进行确认，重点核查：
- 关键数值是否正确
- 对应量纲是否统一
- 材料本身的组成信息是否准确

这一步是为了防止被 KB 中的错误信息误导。例如：Zn-ATA 这个材料的柱撑体也由 ATA 组成（ATA 不仅用于2D层主体，也用于层间柱撑），但这不代表其柱撑体不可替换——把 ATA 换成其他柱撑体不会明显影响拓扑。

> 你必须对 Step 1 的所有材料都严格执行这一步。

## Step 3：排名与报告撰写

### 分析要求

对每个材料都需要分析出：
1. **结构和几何现状**：拓扑类型、孔窗口尺寸、孔腔大小、连通性等
2. **材料潜力**：基于结构和几何的可优化空间
3. **用户需求上的关键性能**：与需求直接相关的数值表现（同一量纲/标准下比较）
4. **局限性**：仅分析**在用户需求上的局限**，不考虑稳定性等无关因素

此外也分析哪些材料是同类的，这一类材料整体是否展示出潜力。

### 排名原则

排名按"**几何潜力 + 传质潜力 + 动力学证据 + 可塑性**"四个维度评分，重要性按此顺序递减。

核心准则：
- **不要把稳定性和可合成性作为推荐理由**，推荐应针对用户需求（如"分离性能"）
- **不要根据证据多少决定排名**
- **潜力大于当前性能**——微调可以带来显著变化

### 输出

撰写一份**中文候选材料报告**，包含每个材料的分析结果、排名及理由（四维度评分）。

### 重要：等待用户反馈

> 候选材料报告完成后，**停下来等待用户反馈**。用户会提供实验结论，告知哪些材料确实有潜力。后续将只针对用户确认的材料进行方向推荐。若用户直接指定了材料和优化方向，则按其指定方向进行推荐。

# 阶段三：候选优化方向推荐

本阶段在用户反馈确认合适的材料后才开始。

## 3.1 任务描述

在保持拓扑不变的前提下，深度研究材料应朝哪方面进行微调/优化，重点包括：
- **合适的孔窗口**
- **合适的柱撑体体积和弯曲角度**
- 其他影响目标性能的结构参数

材料优化是一种**微调**——保持拓扑尽可能不变，让孔窗等影响目标需求的结构发生细微变化。

## 3.2 知识获取与分析

知识来源：
1. 阶段一积累在 research-wiki 中的原理知识（主要依赖）
2. KB V4 原理知识库 + 对应文献原文（辅助）
3. KB V3.4 的 playbook 和 skilllet 中的优化技能
4. `相关文献/扩散相关文献/` 中的文献

从两个知识库分别进行知识学习。

分析角度：从原理机制上，为满足用户需求，这些材料应朝哪些方向优化。原理通常从**结构、几何、扩散能垒**等角度给出方向。

**不考虑**的方向：温度调控、晶粒尺寸、热稳定性、可合成性。除非用户明确指定了这些需求。

## 3.3 正式优化方向推荐流程

对于每一个确认的材料：

### a) 确定优化方向

从原理层面发现当前材料在哪些方面有局限，制定针对性的优化方向。每个优化方向必须讲清楚：
- **为什么需要优化这个方向？**（当前局限是什么）
- **这个优化方向需要对材料做什么改动？**
- **优化的原理/机制是什么？**

### b) 明确优化策略

每个优化方向应明确：
1. **设计原则**
2. **具体优化策略**
3. **候选组成推荐**：推荐一组可替换的合适组成（如改柱撑体，则推荐至少 **10个** 候选柱撑体），给出英文和中文名称

### c) 遵循循序渐进原则

每个方向上只优化一个组成（如只换柱撑体或只换配体），避免同时替换多种组成导致跳跃太大。

- 不需要改动的组分：候选选定为当前材料本身的组分
- 需要优化的组分：给出合适的候选空间

### d) 优化必须有原理依据

优化不是随意替换组成，必须从原理层面验证确实需要优化某方向，再对组成进行修改。

## 3.4 候选方向评分与排名

### 方向评分

根据潜力对所有优化方向进行评分和排名。

### 候选组成评分

每个方向中推荐出的可替换组成也需要评分。

### 评分标准

评分围绕用户的研究目的设计，需包含对微调后以下指标的影响评估：
1. **孔窗口**
2. **孔腔体积/尺寸**
3. **Qst**
4. **扩散时间常数**
5. **动力学选择性**

前三项影响后两项，后两项直接关联用户的目标需求。基于前期文献学习，给出各指标"好的范围"的定量标准，然后统一给出评分逻辑和分数。

# 最终报告

完成所有分析后，撰写一份**完整的中文候选推荐报告**，以 markdown 格式写入文件。如果行数超过300行，请分批写入。

## 报告章节

报告至少包含以下章节：

1. **任务背景与挑战**：用户需求概述、关键难点分析
2. **已有候选材料分析**：每个候选材料的详细分析（结构、几何、性能、潜力、局限）
3. **优化核心原理总结**：从原理层面总结的关键优化思路
4. **各材料候选优化方向**：每个材料的优化方向详解（含设计原则、具体策略、候选组成及评分）
5. **全局优先级排序**：综合考虑潜力和机理，给出已有材料+优化方向的全局排名

内容要详细丰富、专业严谨。排序需充分考虑潜力和机理，不能只看数值，也不要关注用户需求外的因素。
