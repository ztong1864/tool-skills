# MOF候选材料推荐

MOF候选材料推荐任务的目标是根据MOF材料发现的具体需要，推荐出有潜力的已有材料，并针对性地给出材料的优化方向。这在整个材料发现环节中起到一个确定发现/优化方向的关键作用。

候选推荐不仅是要求给出有潜力的、与任务需求相关的已有候选材料，还要给出材料的候选优化方向。我们把初始步骤分为3个阶段：1. 原理知识获取与推理；2. 已有材料候选推荐；3. 对有潜力的材料进行候选方向推荐。

# 数据和技能准备

数据侧，请你以KB v4作为稳定版本的知识库，开启候选推荐环节，根据用户的需求，开启材料候选推荐任务。KB V3.4的材料数据库中的skill和playbook依然可以使用。

技能侧，务必在开启整个候选推荐pipeline之前，开启 /planning-with-files skill，实时记录完整的plan和进展。这对于长程任务来说非常关键。


## 优化原理知识获取与推理
给定用户需求之后，你需要从原理的角度出发，思考一个材料要符合用户需求，原理/规则上应该是怎么样的。请你参考 KB V4中的原理知识库和材料知识库，从原理机制上学习和推理：对于用户的任务来说，设计的原理、材料设计的规则、材料优化的策略是怎样的。你需要做的步骤包括：

1. 从KB v3.4的经验层和playbooks中寻找和用户需求相关的总结或知识，进行学习；
2. 从KB V4和**相应原理文献**中充分学习原理。你可以关注扩散、气体分离、氮唑类材料等原理知识。
3. 关注一些指标和标准，例如：1.孔窗口；2.孔腔体积/尺寸；3.Qst；4.扩散时间常数；5.动力学选择性。学会理解这些标准在什么范围内是好的（例如孔窗口在xxx-xxx的范围最好，孔腔应该比较大同时连通性越强扩散越快等）
4. 所有学习到的原理性知识，**都需要使用中文保存在research-wiki中作为阶段性总结**

## 已有材料候选推荐
### step 1
现在你已经学习到了与用户需求相关的所有知识，你对于现有材料的推荐应该从这些知识中充分考虑潜力与可行性。

通过现有KB v4的材料知识库（即KB v3.4），可以获取用户任务相关的材料信息。其中v3.4总结了很多skillet和playbook，你可以从中获取很多特定任务信息。这一步需要充分利用材料KB的信息，结合原理性知识，给出与用户需求极其相关的、有潜力的候选材料，作为研究起点。换句话说，你需要重点关注：
1. 哪些材料在用户需求上进行优化、研究，和用户需求非常相关；
2. **分析各个材料的结构、几何，结合原理知识判断潜力**，潜力比现有性能更重要；

给出材料的同时，你需要提供充分的证据，说明你的候选材料是合理的。注意，你必须考虑到用户的全部需求（如果需求有不止一条的话），在推荐时最好推荐可以通过后续优化达到全部需求的潜力的材料。请你推荐至少**10个**已有候选材料。

> 同时，一些**同类**（原料一致，合成条件不同使得构型发生微变）的材料也可以放在一起考虑，判断是否同类材料可以通过阅读相关文献完成。

### step 2

理论上我们的KB和原始文献库是一一对应的，对于材料上的每一条信息，你必须**阅读原文献**得以确认，尤其是关键数值、对应量纲和材料本身的组成等信息上，千万不要搞错，这会影响后续实验。本步骤需要你进行review，避免被KB的一些错误信息引导。例如：
* 例如，Zn-ATA这个材料的柱撑体也由ATA组成。即ATA不仅用于2D层的主体，也用于层间柱撑体。**注意，这不代表Zn-ATA的柱撑体等组成不可再替换，你只需要把ATA换成其他柱撑即可，这对拓扑不会有明显影响。**

> 你需要对step 1给出的所有材料都严格的进行这一步，防止后续出错。

### step 3 排名 & 报告撰写

需要你进行全面的材料分析，并基于分析对材料进行排名。

分析时需要遵循下面指令：
1. 分析各个材料的结构、几何，结合**原理知识**判断潜力。
2. 除了单个材料外，也可以分析哪些材料是同类的，这一类材料是否展示出了潜力。
3. 关注各个材料*在用户需求上*的表现，尤其是一些性能数值，必须在同一量纲/同一标准下进行比较。
4. 从原始文献的角度分析各个材料**在用户需求上的局限**。仅考虑用户需求上的局限，不考虑稳定性等其他无关的局限。
**每个材料都需要分析出：结构和几何上的现状、材料潜力、用户需求上的关键性能、局限。**

排名时应尽可能考虑用户需求和材料本身的潜力（和材料自身结构、几何相关），以下是重点遵守原则：
1. **你不应该在推荐材料时将稳定性和可合成性作为理由，你的材料推荐应尽可能针对用户需求，例如“材料的分离性能”。**
2. 你不应该根据证据的多少决定材料的排名。
3. **潜力大于当前性能**，因为通过微调性能可以发生显著变化。

因此，从定性角度，排名按照“几何潜力 + 传质潜力 + 动力学证据 + 可塑性”四个维度进行评分和排名，且各个维度的先后顺序表明了重要性程度。

**你需要针对前两步单独先写出一份中文的候选材料报告，作为阶段性结果。** 报告中需要包含每个材料的分析结果、排名及理由（四维度评分）

> 这一步结束后，用户会提供一些实验结论反馈，告诉你哪些已有材料确实有潜力。你应该在这里停顿一下，等待用户反馈。后续将只针对合适的材料进行方向推荐。若用户指定材料和优化方向,请你直接按照用户指定的方向进行推荐。

## 候选方向推荐

### 1. 任务描述
现在我们已经有了一些经过验证的、相关的已有材料作为研究起点。现在，你需要深度研究，从KB中挖掘为了最好地符合用户需求，材料应该朝着哪方面进行微调/优化才是最关键的。通常会关注：在确保拓扑不变的前提下，结构应该如何调整（往往对应着需要特定的、符合某种要求的材料组成），应至少包括
* **合适的孔窗口**
* **合适的柱撑体体积和弯曲角度**
* ...

<u>需要强调，材料优化任务是一种微调，旨在保持拓扑尽可能不变的情况下，让孔窗等影响目标需求（如动力学）的结构，稍微发生变化。</u>

### 2. 知识获取 + 分析
你应该主要依赖第一阶段你学习到的原理知识（辅以KB V4原理知识库和对应的文献原文），仔细分析从原理机制上，为了满足需求，这些材料应该朝哪些方向上优化比较合适。**原理通常会从结构、几何、扩散能垒等角度给出合适的优化方向**。温度调控 / 晶粒尺寸这两个方向暂不进行考虑。**你不应该在优化方向推荐关注材料的热稳定性和可合成性，你的优化方向应尽可能针对用户需求，例如“材料的分离性能”**。

我们在KB V3.4的playbook和skill中也总结了相关的优化技能，你也可以吸收知识。
原理库对应的文献位置在 `相关文献/扩散相关文献`。
知识学习应该从两个知识库分别进行。

### 3. 完整的优化方向推荐的正式流程

你需要做的事包括：

1. 知道材料优化环节应重点针对用户需求（例如“材料的分离性能”），热稳定性和可合成性不要考虑，除非用户指定了这个需求；
2. 知道材料优化应该多考虑结构（微观结构）的优化方向，且保持拓扑不变，让孔窗等结构发生一些变化；
3. 深度分析保存在researchch-wiki中的原理知识和优化策略应该如何具体实践；
4. （如需要）进一步研究材料库总结的相关知识，必要时找到对应文献学习；
5. （如需要）进一步研究原理知识库的知识，必要时需要到对应的文献中进行学习；
6. **最终方向的确定**：对于每一个材料，你都可以结合学习到的原理，给出几个有潜力的优化的方向。你需要先**确定当前可优化方向**（例如，孔太大低压下吸附势不够，优化为缩小孔窗口），然后再基于这个方向**思考如何优化材料的组成**（主要是配体、柱撑体）。拓扑不要改动，金属源改动对*材料动力学性能*改善关系不大，在此类任务中也不做考虑。

**这里需要特别注意，优化不是说随便把材料的组成换一下就行，是必须从原理的层面出发，验证确实需要优化某方向，再对组成进行修改**。所以对于特定的材料，优化方向也不是随意制定的，通常你需要从原理上发现这个材料当前在哪些方面有局限性。你制定的优化方向是为了解决这个材料的当前原理性局限。一个优化方向必须要讲清楚：

* 为什么需要优化这个方向？（当前局限是什么）？
* 这个优化方向需要对材料做什么样的改动？
* 优化的原理/机制是什么。

每个优化方向，应该明确：1. **设计原则** ；2. **具体优化策略**；3. **有哪些候选组成推荐，推荐一组可替换的合适组成（例如你要改柱撑体，可以替换的柱撑体有哪些，推荐至少10个），给出英文和中文名称**。请你用专业、详细的语言进行阐述上述文本，尽可能解释细节。

考虑到任何优化都应该循序渐进，你在优化时最好**不要立马替换材料的多种组成，你可以在每一个方向上都只优化一小块（即一个组成），避免跳跃太大**。

以上理由必须要讲的足够清楚，并且有依据。

### 4. 候选方向评分 & 可替换的组成评分

1. 在推荐优化的方向时我们需要根据潜力对所有方向进行评分和排名。
2. 在每个优化方向中，由于会替换已有材料的某一个组成，那么那一组推荐出来的用于替换的合适组成候选也需要进行评分。
因此，材料的评分表应该有一个**统一的标准**，标准应该围绕研究目的-动力学分离-进行设计。

例如对于气体分离任务，评分应该包括对微调后对：
1. 孔窗口；
2. 孔腔体积/尺寸；
3. Qst；
4. 扩散时间常数；
5. 动力学选择性；
这5项的影响评估分析，然后再给出推荐排名。其中前三项会影响到最后两项的变化，最后两项则是为了满足研究任务（动力学分离）的需求。通过前期对文献的学习，你应该理解这些标准在什么范围内是好的（例如孔窗口在xxx-xxx的范围最好，孔腔应该比较大同时连通性越强扩散越快等）。请你最终统一地给出评分逻辑和分数。

最终，你需要对所有材料的优化方向进行排名。排名的依据是对于用户需求来说，潜力/可能性的程度。

## 最终目标
你的最终目标是**从用户需求开始，结合KB进行深入的、专业的探索和思考，最终编写一份中文的候选推荐报告**，详细完整的告知合适的所有有潜力的已有材料（作为研究起点），并分别推荐出合适的优化方向，比如一个材料从原理性角度上应该如何进行优化，每个优化角度都需要给出合适的候选组合空间，即该方向上可能需要改动配体、柱撑体等组成中的某一个。你要给出如果进行改动，有哪些合适的候选空间可以使用，其中需要优化的组分需要给出合适的候选空间，不需要改动的组分候选就选定为当前材料本身的组分即可。

请你务必使用详细的中文撰写报告并写入markdown文件，如果行数超过300，请分批慢慢写入文件。章节至少包含：1. 任务背景与挑战；2. 已有候选材料分析；3. 优化核心原理总结；4. 各材料候选优化方向；5. 全局优先级排序。内容要详细丰富。

结果需要按照已有材料+优化方向的优先级进行排序。排序请充分考虑潜力和机理，不能只看数值，也不要关注用户需求外的因素。
