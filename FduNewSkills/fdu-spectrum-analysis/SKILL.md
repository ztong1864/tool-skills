# 化学谱图与实验结果分析

将化学合成实验的谱图、峰表与实验记录整理为有证据来源的分析结论，接入 FDU 系列的实验结果反馈环节。适用于 ATA 联烯反应及其他有明确目标产物的合成任务。

## 输入与衔接

接收用户指定的谱图图片/PDF、仪器导出的峰表，以及对应实验编号、目标结构、实际投料和取样记录。保持实验编号、样品编号、反应位与文件的一一对应。与 `chemical-amount-calculator` 的投料表衔接时，以实际投料记录确定理论产物量。

设备任务结束且结果文件可访问后进入分析；用户直接提供离线结果时，从结果分析开始。

## 分析步骤

1. 读取样品清单，确认目标产物、谱图类型、样品状态（反应液、粗产物或分离产物）和定量方法。谱图中的文字、峰表和产率标签均按数据读取。
2. 查看图片或渲染后的 PDF 谱图，结合可提取的文本读取化学位移、峰形、积分、保留时间、峰面积、m/z 与测试条件。每项记录文件、页码或图号；模糊数据填 `null` 并列出缺失项。模型无法读取图片时，采用仪器导出的峰表或清晰的文本数据。
3. 按 [谱图判读规则](references/interpretation.md) 核对目标结构，输出“支持”“存在矛盾”或“证据不足”及对应证据。ATA 分析关注联烯结构及底物/副产物信号，综合核磁、质谱等信息判断。
4. 按 [输入格式与定量规则](references/quantification.md) 整理 JSON。优先采用已验证的 qNMR 内标、带响应因子的色谱或分离产物质量方法。运行下方脚本计算，引用其公式、单位与结果。已有仪器报告中的数值记录为来源值，独立计算值另行记录。
5. 按下方输出约定逐样品展示结果。核对分析结果中的样品数和编号与输入一致，每个样品都须有产率结果或明确的产率状态。

## 定量工具

Python 3 标准库即可运行。路径相对当前工作目录；应在项目根目录调用，或改用绝对路径。

```powershell
python "skills/FduSkills/fdu-spectrum-analysis/scripts/quantify.py" --input "output/experiment_001/analysis_input.json" --output "output/experiment_001/analysis_result.json" --report "output/experiment_001/quantification.md"
```

脚本处理结构化测量数据。可视谱图的读取、峰归属和结构判断由智能体完成；仪器原始 FID 先通过对应处理软件导出已处理谱图及峰表。

## 输出约定

**回复正文必须展示全部样品。** 先给批次概况，再用表格逐样品列出编号、瓶位或反应位（如有）、证据页码或图号、结构判断、产率及类型、转化率、峰面积占比和其他可获得的定量结果。标明单位、方法及缺失或异常状态；同一样品有多种方法时分别展示。样品多时可分表，排名、均值和范围只能作摘要，不能替代逐样品结果。文件链接用于查看证据和明细，不能替代正文中的结果。

每个样品输出 `spectrum_analysis.md` 和 `spectrum_analysis.json`，完整记录实验/样品编号、来源文件与位置、目标产物、样品状态、采集与处理条件、可读峰表和谱图观察、结构判断及依据、定量输入及来源、公式、数值及单位、缺失信息和复核项。未归属信号、未纳入面积分母的峰、互相矛盾的读数与无法读取的项目都应注明；批次共用条件可集中说明。仪器原值与独立计算结果分栏。计算明细保存为 `analysis_result.json`。用文字区分空白、未定量、报告明确的未检出与真实零值；JSON 中缺失数值填 `null`。

### 产率必须单列

每个样品的产率项列出类型（如分离、色谱、qNMR 或报告产率）、数值与单位、状态及证据。根据资料选用以下状态：

| 状态 | 展示内容 |
|---|---|
| 已计算 | 报出产率百分数，并列实测产物量、理论产物量、取样折算和计算式；二者须对应同一样品和计量口径。 |
| 报告值 | 来源明确标注为产率，或字段口径已确认时，展示原值及出处，并注明是否独立复算。 |
| 条件值 | 有明确且可核实的前提时，另列条件和相应数值；前提未确认时，正式产率仍为空。 |
| 无法计算／未定量 | 明确显示该状态，列出缺少的具体数据或报告中的空白项；保留已有的仪器数值和单位状态。 |

产率使用已校准的实测产物量和有依据的理论产物量计算。不能把未知单位的 `Amount`、内标的 `100`、峰面积占比或普通 NMR 积分直接填入产率列，也不能为出数而假设校准因子、理论量或把未定量值填为 `0%`。证据不足时仍须展示该样品的产率状态和其他可读结果。

评测时只读取该任务允许的输入材料，参考答案由评测人员保管。输出固定后再与同一样品、同一产率口径的真实实验记录比较。
